# Kunde (arkivert 2023)

**Gammel** versjon av kundemodellen. Har samme filnavn som `domene/Kunde.md` – gjør `[[Kunde]]` tvetydig.

```java
public class Kunde {
    private Long id;          // før vi gikk over til UUID
    private String fornavn;
    private String etternavn;
}
```
