# v1.1 – Lesekomfort og tastaturstyring

Status: **Godkjent av kunden 2026-11-06**. Eier: PO. Bygger på v1 (`docs/produkt/brief.md`).

## Overordnede prinsipper (bindende)

- **P1 Frontmatter er data, ikke presentasjon.** Ingen visningsvalg skal leses fra eller skrives til notatene. Alt visningsvalg lever i leseren (Utseende, hurtigtaster, kommandopalett, nettleserens lagring).
- **P2 Ett kommandoregister.** Alle handlinger registreres ett sted (id, navn, beskrivelse, gruppe, tastebindinger per *modus*, tilgjengelighet). Kommandopalett, hurtigtastoversikt (`?`) og README-tabellen genereres fra registeret. Ingen hurtigtaster utenfor registeret.
- **P3 Modi fra start.** Tastaturmotoren har eksplisitte modi. I v1.1 finnes kun `normal` (lesing). Strukturen skal tillate `insert` (og evt. `visual`) senere uten omskriving.
- **P4 Reserverte taster** (fremtidig redigering, vim): `i a o e I A O s c d x p y u r` samt `Esc` som «gå ut av modus». Disse kan ikke bindes i normal-modus i v1.1 (håndheves av test). `Esc` brukes i v1.1 kun til å lukke/avbryte (palett, dialoger, zen).
- **P5 Norsk tastatur.** Ingen bindinger som krever ⌥ på norsk Mac-layout (bl.a. `[ ] { } \ | @ $`).
- **P6 Ikke-vim-brukere** skal fortsatt ha `⌘K` og `⌘.`; alt skal også kunne nås med mus (Utseende/palett).
- **P7 Hurtigtaster er inaktive** når fokus er i et tekstfelt, og når en modal dialog har fokus (unntatt dialogens egne taster og `Esc`).

## Funksjoner

### F1 Lesebredde
- To tilstander: **Leseoptimalisert** (dagens, standard) og **Full bredde**.
- Full bredde: hele innholdet, også brødtekst, flyter over tilgjengelig bredde mellom venstre panel og høyre marg. Panelene beholdes.
- Global, huskes i nettleseren. Valg i Utseende + kommando + hurtigtast.

### F2 Diskré embedding
- Av/på **per notat**, huskes i nettleseren (nøkkel: vault-id + notatsti). Gjelder kun det åpne notatet; andre notater er upåvirket. Valg i Utseende («Diskré embedding – dette notatet») + kommando + hurtigtast. Kort bekreftelse (toast) ved bytte.
- Gjelder kun **innebygde notater** (`![[notat]]`, `![[notat#seksjon]]`, `![[notat#^blokk]]`). Innebygde baser og bilder er uendret.
- I diskré modus:
  - Ingen ramme, ingen «Innebygd fra»-etikett, ingen «Åpne notat»-knapp. Innholdet glir inn i brødteksten.
  - Notatembed: notatets tittel vises som overskrift **ett nivå under nærmeste foregående overskrift** i vertsnotatet (H1-kontekst → H2, osv., maks H6). Seksjonsembed: seksjonens egen overskrift brukes, justert til samme nivålogikk. Blokkembed: ingen overskrift.
  - Overskrifter fra innebygde notater blir med i **innholdsfortegnelsen** og **§-nummereringen** som én sammenhengende tekst, og kan foldes (F3).
  - **Kildelenke ved hover/fokus:** en diskré lenke til kildenotatet vises ved hover på (eller tastaturfokus i) den innebygde seksjonen.
  - Nestede embeds arver diskré modus.
  - Feiltilstander (manglende notat, syklus, dybdegrense) vises **alltid** synlig, også i diskré modus.

### F3 Folding av overskrifter
- Alle nivåer (H1–H6). En seksjon løper til neste overskrift på samme eller høyere nivå.
- Fold-pil vises ved **hover eller tastaturfokus** på overskriften. På berøringsskjerm (ingen hover) vises pilen alltid, dempet.
- Foldet overskrift har en diskré indikator på at innhold er skjult.
- Folding **huskes ikke** – alt er utfoldet når et notat åpnes.
- Navigasjon til `#overskrift`, klikk i TOC, søketreff og `#^blokk` folder ut det som trengs automatisk.
- Innebygde notater kan **ikke** foldes som én blokk (men overskrifter i dem kan, jf. F2).
- Tilgjengelighet: pilen er en knapp med `aria-expanded` og navn («Fold sammen ‹overskrift›»).

### F4 Zen-modus
- Skjuler begge panelene (navigasjon, høyre marg) og øvrig «krom» (statuslinje, mobil-topplinje). Notatets tittel og properties beholdes. Innholdet sentreres.
- **Ikke** nettleserens fullskjerm. **Ingen** avsnittsdemping (ev. senere).
- Kombinerbar med F1 (full bredde).
- Hurtigtaster og palett virker i zen; navigasjon mellom notater beholder zen.
- Avsluttes med samme hurtigtast, `:zen`, eller `Esc` (når ingen dialog er åpen).
- **Huskes ikke** – leseren starter alltid i vanlig visning.

### F5 Kommandopalett (felles med søk)
- Én palett. Åpnes med `⌘K`, `/` (tom → notatsøk) eller `:` (forhåndsutfylt med `:` → kommandomodus).
- Uten prefiks: notatsøk som i dag. Med `:`-prefiks: kommandoer fra registeret, fuzzy-søk på navn og aliaser (`:bredde`, `:zen`, `:diskret`, `:tema terminal`, `:palett fosfor`, `:lys`, `:mørk`, `:fold alle` …).
- Hver kommando viser sin hurtigtast til høyre. Kommandoer med argument (tema/palett) tilbyr verdiene som underlister.
- Kommandoer som ikke gir mening i gjeldende kontekst (f.eks. diskré embedding på en `.base`-side) vises deaktivert med forklaring.

### F6 Hurtigtastoversikt
- `?` åpner et panel med alle hurtigtaster, gruppert (Navigasjon, Lesing, Visning, Søk og kommandoer), generert fra registeret. Lukkes med `Esc`/`?`.
- Også tilgjengelig fra Utseende og som `:hjelp`/`:taster`.
- README-avsnittet om hurtigtaster genereres fra registeret (`npm run docs:shortcuts`); en test feiler hvis README er utdatert.

### F7 Vim-inspirert navigasjon og leader
- **Leader = `Space`.** Etter `Space` vises (etter ~400 ms uten neste tast) en liten «which-key»-hint med tilgjengelige leader-kommandoer. `Space` alene ruller **ikke** lenger siden (erstattes av `Ctrl d`/`j`).
- Sekvenser (`gg`, `za`, `Space w` …) har tidsavbrudd ~1 s; `Esc` avbryter en påbegynt sekvens.
- Rulling respekterer `prefers-reduced-motion`.

## Tastaturkart v1.1 (normal-modus)

| Taster | Kommando |
|---|---|
| `⌘K` / `/` | Palett – søk i notater |
| `:` | Palett – kommandoer |
| `?` | Hurtigtastoversikt |
| `j` / `k` | Rull ned / opp (ca. 3 linjer) |
| `Ctrl d` / `Ctrl u` | Halv side ned / opp |
| `gg` / `G` | Til toppen / bunnen |
| `H` / `L` | Tilbake / frem i historikk |
| `za` | Fold/utfold seksjonen ved leseposisjon (samme leselinje som TOC, ca. 30 % ned i visningen, eller fokusert overskrift) |
| `zM` / `zR` | Fold alle / utfold alle |
| `Space w` | Bytt lesebredde (F1) |
| `Space d` | Bytt diskré embedding for dette notatet (F2) |
| `Space z` | Zen-modus (F4) |
| `Space m` / `⌘.` | Bytt lys/mørk |
| `Space t` | Åpne Utseende |
| `Esc` | Lukk palett/dialog/oversikt; avbryt sekvens; gå ut av zen |
| `↑↓ ↵`, `⌘↵`, `←→ Home End` | Som i v1 (palett og base-faner) |

Ikke i v1.1: lenkehint (Vimium `f`), avsnittsdemping, skrivemodus.

## Akseptansekriterier

- **AK-1.1-01** Lesebredde kan byttes via Utseende, `Space w` og `:bredde`; valget huskes etter reload; full bredde gir brødtekst bredere enn leseoptimalisert ved 1440 px; ingen horisontal sidescroll ved 360 px i noen tilstand.
- **AK-1.1-02** Diskré embedding kan byttes via Utseende, `Space d` og `:diskret`, gjelder kun gjeldende notat, og huskes per notat etter reload. Andre notater er upåvirket.
- **AK-1.1-03** I diskré modus: ingen ramme/etikett/knapp; tittel som overskrift på riktig nivå; overskriftene med i TOC og §-nummerering; kildelenke synlig ved hover og tastaturfokus; feilkort fortsatt synlige; baser og bilder uendret.
- **AK-1.1-04** Folding på alle nivåer via pil (synlig ved hover/fokus, alltid synlig på touch), `za`, `zM`, `zR`; dyplenker, TOC og søk folder ut; ingenting huskes ved nytt besøk; korrekt `aria-expanded`.
- **AK-1.1-05** Zen skjuler begge paneler og krom; tittel/properties beholdes; virker sammen med full bredde; overlever navigasjon mellom notater; avsluttes med `Space z`, `:zen` og `Esc`; starter aldri aktivert.
- **AK-1.1-06** Én palett: `⌘K`/`/` gir notatsøk, `:` gir kommandoer; alle registrerte kommandoer kan kjøres derfra og viser sin hurtigtast.
- **AK-1.1-07** `?` viser alle hurtigtaster gruppert; innholdet er identisk med registeret; README-tabellen er generert og testet i sync.
- **AK-1.1-08** Ingen reserverte taster (P4) og ingen ⌥-avhengige taster (P5) er bundet (automatisk test mot registeret).
- **AK-1.1-09** Hurtigtaster er inaktive i tekstfelt og bak modal dialog (P7).
- **AK-1.1-10** Ingen endring i notatfiler, og ingen visningsvalg leses fra frontmatter (P1).
- **AK-1.1-11** Alle eksisterende AK fra v1 holder fortsatt (full regresjon grønn), inkl. WCAG AA i alle temaer og AK17-ytelse.
- **AK-1.1-12** Alle nye kontroller er tastatur- og skjermleser-tilgjengelige (axe 0 brudd).
